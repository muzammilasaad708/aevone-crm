# Aevone CRM OS - Replit Deployment Guide

## 🚀 Replit Par Chalane Ka Tarika (Step-by-Step):

### Option 1: Direct File Copy-Paste (Sab Se Asaan)
1. **Replit.com** par jayein aur **Create Repl** par click karein.
2. Template mein **Python** select karein.
3. Apne Repl ke  file mein sara code paste kar dein jo  mein diya gaya hai.
4. **Tools / Dependencies** (ya Shell) mein ja kar ye packages install karein:
   Requirement already satisfied: fastapi in /usr/lib/python3/dist-packages (0.92.0)
Requirement already satisfied: uvicorn in /usr/lib/python3/dist-packages (0.17.6)
Requirement already satisfied: pydantic in /usr/lib/python3/dist-packages (1.10.4)
Requirement already satisfied: requests in /opt/spark/local/lib/python3.11/dist-packages (2.32.5)
INFO: pip is looking at multiple versions of fastapi to determine which version is compatible with other requirements. This could take a while.
   (Ya  file bana kar us mein ye 4 lines daal dein: , , , ).
5. Upar green **Run** button press karein!
6. Replit khud hi **Webview** open kar dega aur aapka **Aevone CRM OS** live chal parega!

---

### Option 2: Full ZIP Upload
1. Replit par naya Python project banayein.
2. Left sidebar mein Files panel par **Upload ZIP** karein ya files drag & drop karein.
3. Green **Run** button dabayein!
